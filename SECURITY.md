# Security policy

## Reporting a vulnerability

Please report security issues by email to [dev@tobias.co.nz](mailto:dev@tobias.co.nz), not in a public GitHub issue.

Include what you found, how to reproduce it, and the version of `@tobias.istvan/dev` you used. You'll get a reply as soon as possible, and a fix will be released before the issue is made public.

## Supported versions

Security fixes go into the latest release only.
