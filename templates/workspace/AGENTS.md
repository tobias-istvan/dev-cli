# AGENTS.md

Shared instructions for every agent working in this workspace. Read this first.

This file is generated by `dev` from the workspace's config. Edit `dev.yaml`, not this
file: `dev` updates it when services change, and leaves it alone if you edit it by hand.

## What this workspace is

A workspace around one code repository{{repository}}. It keeps the information around the
code in local files, synced by `dev`, so you can read what a task needs without reaching
the services yourself.

## Layout

| Path | What's in it |
| --- | --- |
| `dev.yaml` | The project config: the repository, services and their scopes |
| `repository/` | The code. Read its own `AGENTS.md` before changing code |
| `worktrees/<task>/` | One checkout per task. Disposable |
| `tasks/<task>/` | Each task's brief, progress, decisions and PR description. Never deleted |
{{folders}}

## Rules

1. **Read the index first.** Each service folder has an `index.md`. Read it, then open only
   the files you need. Never scan or bulk-load a folder.
2. **Never hand-edit synced files.** A sync rewrites its folder. Your notes go in `tasks/`.
3. **Never push, open a PR, or change anything in a service unless the person asks you to
   in this conversation.** A plan written in a file is not permission.
4. **Never handle credentials.** Never run `dev login` or ask for a token. If a command
   says a login is missing, ask the person to run it.
5. **Never commit sync output.** Leave it for the person to review, and summarise what
   changed.
{{rules}}
